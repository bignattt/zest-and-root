# AI image prompts for Zest & Root (concept)

Works in Midjourney, ChatGPT / DALL-E, Gemini (Imagen), Adobe Firefly and similar tools.
Every prompt ends with the same STYLE LOCK so the five images look like one photo shoot.

## How to keep the set consistent
1. Generate image 1 (hero) first, 4 variants. Pick the best.
2. Use the same tool for all five. If the tool accepts reference images, attach the chosen hero as a style reference for images 2 to 5.
3. Keep the label blank. AI tools garble text on labels. Add the real "Zest & Root" name later in Figma or Photoshop if you want it.
4. Save as the file names in `images/README.md`.

## STYLE LOCK (paste at the end of every prompt)
Photorealistic commercial beverage photography. Soft diffused window light from camera-left with a gentle rim light, natural soft shadows, shallow depth of field, shot on an 85mm lens at f/4, subtle film grain, fresh and honest look with real condensation droplets on the glass. Clear glass bottle with a matte black cap and a simple deep forest green label (#1F4D3A) carrying only a small lemon-yellow circle emblem and no text. Palette of forest green, warm orange (#F59E2A), lemon yellow (#F4D35E) and warm cream (#FBF6EA). No watermark, no logos, no extra text.
