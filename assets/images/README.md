# Image slots

Drop the generated images in this folder with **exactly these file names**.
The pages pick them up automatically. Any missing file falls back to the SVG illustration.

| File name | Ratio | Suggested size | Where it appears |
|---|---|---|---|
| `hero.jpg` | 1:1 | 2000 x 2000 | Landing page hero |
| `product-root-fire.jpg` | 4:3 | 1600 x 1200 | Product card 1 |
| `product-sunrise-zest.jpg` | 4:3 | 1600 x 1200 | Product card 2 |
| `product-green-citrus.jpg` | 4:3 | 1600 x 1200 | Product card 3 |
| `story-ingredients.jpg` | 1:1 | 2000 x 2000 | Ingredient story |

Export as JPG, quality about 80%, so each file stays under roughly 400 KB.
The prompts are in `../image-prompts.md`.
